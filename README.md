# 🏢 Интерактивный справочник ОКВЭД2

Мгновенный поиск по Общероссийскому классификатору видов экономической деятельности (ОК 029-2014, КДЕС Ред. 2). Без рекламы, без регистрации, без установки.

🌐 **Открыть справочник:** [https://prog815.github.io/okved2/](https://prog815.github.io/okved2/)

---

Коллеги, этот справочник создан для тех, кто ежедневно работает с кодами видов деятельности: предпринимателей, бухгалтеров, юристов и специалистов по кадрам. Главная задача — помочь быстро и без ошибок подобрать корректный код ОКВЭД2 для регистрации бизнеса, изменения видов деятельности или статистической отчётности.

## 🎯 Что это и для кого

**ОКВЭД2** — общероссийский классификатор видов экономической деятельности. Гармонизирован с европейской классификацией NACE Rev. 2. Официальный источник — Росстат.

Справочник пригодится, если вам нужно:

- подобрать основной и дополнительные коды ОКВЭД при регистрации ООО или ИП;
- изменить виды деятельности действующей компании;
- указать код в статистической отчётности;
- разобраться, к какой сфере относится тот или иной вид бизнеса;
- найти точное наименование вида деятельности по его коду.

## ⚡ Возможности интерфейса

- **Мгновенный поиск.** Результаты появляются во время ввода — без кнопки «Найти» и без перезагрузки.
- **Поиск по коду — строго с начала кода.** Запросы `01`, `01.11`, `01.11.1` показывают соответствующую ветвь классификатора. Точки в запросе можно не ставить.
- **Поиск по названию.** Одно или несколько слов по логике «И»: `кафе ресторан` найдёт записи, где встречаются оба слова (с учётом синонимов).
- **Фильтр по разделам (A–U).** Удобный выпадающий список, позволяющий сузить поиск до определённой сферы (например, только «Строительство» или «Образование»).
- **Карточки вместо таблицы.** Каждая запись — отдельная карточка: код, уровень (раздел/класс/подкласс/группа/подгруппа/вид), буква раздела и наименование. Так удобнее читать, особенно на телефоне.
- **Кликабельные бейджи разделов.** Клик по бейджу «раздел X» в карточке мгновенно фильтрует выдачу по этому разделу.
- **Описания группировок.** Кнопка `📖 Подробнее` раскрывает официальный текст «Эта группировка включает…», если он есть в источнике.
- **Копирование кода в один клик.** Клик по коду — и он в буфере обмена, а внизу экрана появляется подтверждение.
- **Копирование строки.** Кнопка `📋 строка` копирует пару «код; название» — удобно вставлять в заявления или таблицы.
- **Поделиться карточкой.** Кнопка `📤 Поделиться` открывает системное меню на телефоне или модалку с веб-почтами на компьютере.
- **Прямые ссылки на коды.** Каждый код можно передать коллеге через `?code=…` в адресе.
- **Навигация по странице.** Липкая панель поиска, кнопки `↑`/`↓` в правом нижнем углу.

## 🧭 Как пользоваться

1. **Откройте страницу** — сразу показывается первая порция всех записей.
2. **Начните вводить запрос** в строке поиска — код (например, `56.10`) или название (`кафе`).
3. **Используйте фильтр разделов**, если точно знаете сферу бизнеса (например, раздел `F` — Строительство).
4. **Кликните по коду** в карточке — он скопируется.
5. **Нажмите `📋 строка`**, если нужно скопировать код вместе с названием.
6. **Нажмите `📖 Подробнее`**, чтобы прочитать официальное описание группировки.
7. **Прокручивайте вниз** и нажимайте «Показать ещё +20» — результаты догружаются порциями.

## 📊 Примеры запросов

- `01` — вся ветвь «Растениеводство и животноводство».
- `56.10` — «Деятельность ресторанов и услуги по доставке продуктов питания».
- `62` — «Разработка компьютерного программного обеспечения».
- `торговля` — записи, где в наименовании есть это слово.
- `образование` + раздел `P` — все виды образовательной деятельности.

**Популярные коды:**

- `47` — Торговля розничная;
- `62` — Разработка компьютерного программного обеспечения;
- `49` — Деятельность сухопутного и трубопроводного транспорта;
- `68` — Операции с недвижимым имуществом;
- `85` — Образование.

## 🔗 Прямые ссылки на коды

Каждый код можно открыть напрямую — например:

- `https://prog815.github.io/okved2/?code=56.10` — откроет карточку ресторанов.
- `https://prog815.github.io/okved2/?code=62.01` — разработка ПО.

Ссылка с `?code=` сразу подставляет код в строку поиска и подсвечивает нужную карточку. Удобно отправлять коллеге в письме или чате.

## 🆚 Не путать с соседями

| Справочник | Что это | Когда нужен |
|---|---|---|
| **ОКВЭД2** (этот) | Классификатор **видов экономической деятельности** | Регистрация бизнеса, выбор чем заниматься, статистика, налоги |
| **ОКПД2** | Классификатор **продукции** по видам деятельности | Закупки, отчётность, учёт конкретных товаров |

## ❓ FAQ

**Чем ОКВЭД2 отличается от ОКПД2?**

ОКВЭД2 отвечает на вопрос **«чем занимается компания?»** (виды экономической деятельности). ОКПД2 отвечает на вопрос **«что именно она производит или закупает?»** (продукция). Первые 4 знака часто совпадают, но это разные классификаторы.

**Какой код выбрать: с точками или без?**

Обычно в заявлениях и документах указываются коды с точками (например, `47.11`). В поиске справочника точки можно не ставить — запрос `4711` найдёт то же самое.

**Что означает «раздел» в карточке?**

Вся экономическая деятельность разделена на 21 секцию (от A до U). Например, раздел `A` — Сельское хозяйство, `F` — Строительство, `J` — Информация и связь. Буква раздела всегда отображается в карточке и используется в фильтре.

**Почему у некоторых кодов есть кнопка «Подробнее», а у других нет?**

Кнопка появляется, если в официальном документе Росстата для этой группировки предусмотрено описание («Эта группировка включает: …»). Если описания нет, кнопка не показывается.

**Почему в справочнике 3102 записи, хотя видов деятельности меньше?**

Классификатор имеет иерархию: разделы (A–U), классы (2 цифры), подклассы (3), группы (4), подгруппы (5) и виды (6). Все они являются записями и участвуют в поиске. Для регистрации бизнеса обычно нужны только коды из 4 или более цифр.

**Как найти код для регистрации ИП?**

Введите ключевое слово из вашей сферы (например, `торговля` или `ремонт`), используйте фильтр по разделам, если знаете сферу, и кликните на нужный код, чтобы скопировать его.
