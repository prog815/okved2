# Интерактивный справочник ОКВЭД2

Быстрый, бесплатный и удобный онлайн-справочник по общероссийскому классификатору видов экономической деятельности (ОК 029-2014). Работает как статический сайт — не требует регистрации, подписок или бэкенда.

🌐 **Сайт:** [https://prog815.github.io/okved2/](https://prog815.github.io/okved2/)

## 🎯 Цель проекта

Создать удобный инструмент для предпринимателей, бухгалтеров и юристов, устранив недостатки существующих решений:

- **Сложная навигация** — в нашем справочнике быстрый поиск по кодам и названиям видов деятельности
- **Платные ограничения** — полный доступ без регистрации и подписок
- **Отсутствие удобства** — мгновенный поиск и копирование кодов для регистрации бизнеса
- **Устаревшие данные** — официальный источник Росстата, ежедневное автоматическое обновление

## ✨ Особенности

- **Мгновенный поиск** — результаты появляются при вводе (debounce 200 мс)
- **Раздельная логика поиска:**
  - По кодам: поиск по началу кода (с поддержкой точек: `56`, `56.`, `56.10`, `56.10.1`)
  - По названиям: поиск по подстроке с поддержкой нескольких слов и синонимов
- **Подсветка совпадений** — найденные фрагменты выделяются цветом
- **Копирование кодов** — кликните на код для быстрого копирования в буфер обмена
- **Описания группировок** — кнопка «📖 Подробнее» раскрывает состав группировки «Эта группировка включает…»
- **Индикаторы уровней** — цветные метки для разделов (A–U), классов, подклассов, групп, подгрупп и видов
- **Умная сортировка** — наиболее релевантные результаты показываются первыми
- **Популярные запросы** — быстрые теги для часто искомых видов деятельности
- **Пагинация** — показ первых 50 результатов с кнопкой «Показать ещё» при необходимости
- **Полная автономность** — все данные (3102 записи) загружаются один раз, нет внешних зависимостей
- **Чистый интерфейс** — зелёная цветовая схема, адаптированная под бизнес-тематику
- **Общее меню** — внизу страницы навигация ко всем справочникам проекта

## 🚀 Быстрый старт

Сайт полностью готов к использованию. Просто откройте [https://prog815.github.io/okved2/](https://prog815.github.io/okved2/) и начните поиск.

**Примеры поиска:**

- По коду: `56`, `56.`, `56.10`, `56.10.1`
- По названию: `кафе`, `строительство`, `услуги перевозки`, `розничная торговля`

**Популярные запросы:**

- 🍽️ **Общественное питание:** кафе, ресторан, столовая
- 🏗️ **Строительство:** строительные работы, ремонт, монтаж
- 🚚 **Транспорт:** перевозки, логистика, грузоперевозки
- 🛒 **Торговля:** розничная торговля, оптовая торговля
- 💼 **Услуги:** консалтинг, аренда, консультации

## 📅 Актуальность данных

**Последнее обновление:** 1 октября 2026

Данные автоматически обновляются из официального источника — [Росстат](https://rosstat.gov.ru/classification). Справочник содержит **3102 записи** всех уровней иерархии (разделы A–U, классы, подклассы, группы, подгруппы, виды).

## 🛠 Как это работает

Сайт построен как статическая веб-страница — все данные загружаются один раз при открытии, поиск работает мгновенно прямо в вашем браузере. Нет серверных запросов, нет задержек, нет зависимости от внешних сервисов.

**Официальные источники:**

- [Росстат](https://rosstat.gov.ru/classification) — официальный источник данных
- [КонсультантПлюс](https://www.consultant.ru/document/cons_doc_LAW_163320/) — правовая база
- [ГАРАНТ](https://base.garant.ru/70650726/) — справочная правовая система

## 🔗 Связанные проекты
