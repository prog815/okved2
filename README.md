# 🏢 Интерактивный справочник ОКВЭД2

Онлайн-справочник по Общероссийскому классификатору видов экономической деятельности (ОК 029-2014, КДЕС Ред. 2). Справочник создан на основе официального машиночитаемого снимка.

🌐 Сайт: [https://prog815.github.io/okved2/](https://prog815.github.io/okved2/)

Этот справочник — для тех, кто ежедневно работает с кодами видов деятельности: предпринимателей, бухгалтеров, юристов, кадровиков и разработчиков учётных систем. Главная задача — помочь быстро и без ошибок подобрать корректный код ОКВЭД2 для регистрации бизнеса, изменения видов деятельности или статистической отчётности.

---

## Что кодирует ОКВЭД2

**ОКВЭД2** — общероссийский классификатор, в котором записаны **виды экономической деятельности**. Он отвечает на вопрос **«чем занимается компания»**. Классификатор гармонизирован с европейской классификацией NACE Rev. 2 (коды и наименования до 4 знаков включительно сохранены).

В текущем снимке справочника содержится порядка **3100 записей**. Классификатор представлен плоским списком (без дерева в интерфейсе), но с сохранением иерархии через структуру кода:

- **Раздел** (буква A–U, например `A`).
- **Класс** (2 цифры, например `01`).
- **Подкласс** (3 цифры, например `01.1`).
- **Группа** (4 цифры, например `01.11`).
- **Подгруппа** (5 цифр, например `01.11.1`).
- **Вид** (6 цифр, например `01.11.11`).

> **Важно про ОКПД2.** ОКВЭД2 и ОКПД2 — это разные классификаторы. ОКВЭД2 отвечает на вопрос «чем занимается компания?» (виды деятельности), а ОКПД2 — «что именно она производит или закупает?» (продукция). Первые 4 знака часто совпадают, но это разные справочники. Если в форме запрашивается код продукции, используйте [соответствующий справочник](https://prog815.github.io/okpd2/).

## Для кого и зачем

Справочник предназначен для предпринимателей, бухгалтеров, юристов, специалистов по кадрам и разработчиков учётных систем (1С, SAP, ERP).

Он пригодится, если вам нужно:
- подобрать основной и дополнительные коды ОКВЭД при регистрации ООО или ИП;
- изменить виды деятельности действующей компании;
- указать код в статистической отчётности;
- разобраться, к какой сфере относится тот или иной вид бизнеса;
- найти точное наименование вида деятельности по его коду.

## Возможности интерфейса

- **Мгновенный поиск.** Результаты появляются по мере ввода — без кнопки «Найти» и без перезагрузки.
- **Поиск по коду.** Введите `56.10` или `5610` (с точками или без). Поиск строго с начала кода.
- **Поиск по названию.** Одно или несколько слов в любом порядке по логике «И»: `кафе ресторан`.
- **Смешанный запрос.** Введите `62 разработка` — найдёт все объекты, где код начинается с `62` **и** в названии есть «разработка».
- **Копирование в один клик.** Клик по коду копирует его в буфер обмена. Внизу экрана появится подтверждение.
- **Описания группировок.** Кнопка `📖 Подробнее` раскрывает официальный текст «Эта группировка включает…», если он есть в источнике.
- **Фильтры.** Чекбоксы для выбора уровней (раздел, класс, подкласс, группа, подгруппа, вид) и выпадающий список для выбора раздела (A–U). Бейджи уровней и разделов в карточке тоже кликабельные.
- **Поделиться карточкой.** Кнопка `📤 Поделиться` открывает системное меню на телефоне или модалку с веб-почтами на компьютере. В текст автоматически подставляются наименование, ссылка, код, уровень и раздел.
- **Прямые ссылки на коды.** Каждый код можно передать через `?code=…` в адресе.
- **Подсветка совпадений.** Искомые слова и цифры выделяются прямо в карточке.

## Примеры запросов

- `56.10` — «Деятельность ресторанов и услуги по доставке продуктов питания».
- `62` — «Разработка компьютерного программного обеспечения».
- `торговля` — записи, где в наименовании есть это слово.
- `образование` + раздел `P` — все виды образовательной деятельности.

**Популярные коды:**
- `47` — Торговля розничная;
- `62` — Разработка компьютерного программного обеспечения;
- `49` — Деятельность сухопутного и трубопроводного транспорта;
- `68` — Операции с недвижимым имуществом;
- `85` — Образование.

## Прямые ссылки на коды

Каждый код можно открыть напрямую — например:
- `https://prog815.github.io/okved2/?code=56.10` — откроет карточку ресторанов.
- `https://prog815.github.io/okved2/?code=62.01` — разработка ПО.

Ссылка с `?code=` сразу подставляет код в строку поиска и подсвечивает нужную карточку. Пока идёт deep-link, поиск работает по точному совпадению кода.
