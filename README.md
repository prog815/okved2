# Интерактивный справочник ОКВЭД2

Быстрый, бесплатный и удобный онлайн-справочник по общероссийскому классификатору видов экономической деятельности (ОКВЭД2). Работает как статический сайт на GitHub Pages — не требует регистрации, подписок или бэкенда.

🌐 **Сайт:** [https://prog815.github.io/okved2/](https://prog815.github.io/okved2/)

## 🎯 Цель проекта

Создать удобный инструмент для предпринимателей, бухгалтеров и юристов, устранив недостатки существующих решений:
- **Сложная навигация** — в нашем справочнике быстрый поиск по кодам и названиям видов деятельности
- **Платные ограничения** — полный доступ без регистрации и подписок
- **Отсутствие удобства** — мгновенный поиск и копирование кодов для регистрации бизнеса

## ✨ Особенности

- **Мгновенный поиск** — результаты появляются при вводе (debounce 200ms)
- **Раздельная логика поиска**:
  - По кодам: поиск по началу кода (с поддержкой точек: `56`, `56.`, `56.10`, `56.10.1`)
  - По названиям: поиск по подстроке с поддержкой нескольких слов и синонимов
- **Подсветка совпадений** — найденные фрагменты выделяются цветом
- **Копирование кодов** — кнопка 📋 рядом с каждым кодом для быстрого копирования
- **Ссылки на официальные источники** — иконки ⚖️ (КонсультантПлюс) и 🏛️ (ГАРАНТ) для перехода к подробной информации
- **Индикаторы уровней** — цветные метки для разделов, классов, подклассов и групп
- **Умная сортировка** — наиболее релевантные результаты показываются первыми
- **Популярные запросы** — быстрые теги для часто искомых видов деятельности
- **Пагинация** — показ первых 50 результатов с кнопкой "Показать все"
- **Полная автономность** — все данные (~3k записей) загружаются один раз, нет внешних зависимостей
- **Чистый интерфейс** — фиолетовая цветовая схема, адаптированная под бизнес-тематику

## 🛠 Технологии

- **Фронтенд:** Чистый HTML, CSS, JavaScript
- **Поиск:** Кастомный алгоритм с поддержкой синонимов и уровней иерархии
- **Хостинг:** GitHub Pages
- **Данные:** Статический JSON (2 929 записей ОКВЭД2, ~500 KB)
- **Интеграция:** Общее навигационное меню для связи со справочниками ОКПД2 и ПП 1875

## 🔄 Обновление данных

Когда требуется обновить данные классификатора:

1. Скачайте актуальный справочник в CSV формате с [classifikators.ru/okved](https://classifikators.ru/okved)
2. Сохраните файл как `okved.csv` в кодировке UTF-8
3. Запустите конвертацию: `python convert_to_json.py`
4. Файл автоматически определит кодировку и создаст `data.js`
5. Обновите дату актуальности в `index.html` (футер)
6. Закоммитьте изменения: `git commit -am "Обновление данных" && git push`
