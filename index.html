🏢 Интерактивный справочник ОКВЭД2

Общероссийский классификатор видов экономической деятельности (ОК 029-2014)

Используется для государственной регистрации юридических лиц и индивидуальных предпринимателей, статистического наблюдения, анализа и прогнозирования социально-экономического развития. Основан на европейской классификации NACE Rev. 2. Подробнее в Википедии.

В справочнике актуальная база из 2929 записей. Данные обновляются с официальных источников.

Поиск запустится автоматически при вводе.
Популярные запросы: кафе, строительство, перевозки, розничная торговля
📋 Как пользоваться справочником:
  • Поиск по коду: Введите код полностью (56.10) или частично (56)
  • Поиск по названию: Введите одно или несколько слов (кафе ресторан)
  • Копирование: Кликните на код для копирования в буфер обмена
  • Навигация: Используйте общее меню для перехода к другим справочникам
